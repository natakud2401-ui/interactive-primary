# Математическое моделирование — сайт 1–4 классов

Вход на сайт: `modeling/index.html`. Учебная программа: 135 тем, 4 пробных теста, тренажёр «Изменяем размеры модели» ссылается на существующий файл в корне репозитория.

## Текущее состояние

- Ученик выбирает класс, тему, вводит учебный код и проходит тест.
- Ответ и правильное решение появляются сразу после выбора.
- Результат сохраняется только в localStorage браузера и может быть выгружен в CSV для Excel.
- **Результаты разных устройств пока не собираются.** Не представлять локальный журнал как общий.
- Пробные задания не подменяют полного содержания всех 135 уроков.

## Как подключить общий журнал без школьного сервера

1. Создайте приватную Google Таблицу под учётной записью учителя. Не выдавайте доступ ученикам.
2. Откройте **Расширения → Apps Script**, вставьте содержимое файла `backend.gs` и сохраните.
3. Выберите **Развернуть → Новое развертывание → Веб-приложение**. Выполнять от имени: **меня**. Доступ: **все**, чтобы дети могли отправлять результаты без аккаунта Google. Скопируйте URL, оканчивающийся на `/exec`.
4. В `index.html` задайте `CLOUD_ENDPOINT` равным URL приложения, а `SHEET_URL` — закрытой ссылке учителя на таблицу.
5. Протестируйте отправку со второго устройства и проверьте появление строки. Кнопка «Учителю» на публичном сайте не защищена: общий журнал открывайте только в Google Таблице с учётной записью учителя.
6. В Google Таблице выберите **Файл → Скачать → Microsoft Excel (.xlsx)** при необходимости.

**Конфиденциальность:** в публичную систему следует вводить коды учеников, не фамилии, до согласования обработки персональных данных детей со школой и родителями. Общедоступный endpoint может принимать посторонние отправки; скрипт проверяет формат, но не гарантирует защиту от поддельных попыток. Для официального оценивания нужна аутентификация ученика, а не только код.

**Ограничение ChatGPT Sites:** официальные правила Sites запрещают создавать сайты, ориентированные на детей младше 13 лет. Поэтому этот проект предназначен для собственного GitHub Pages и отдельного хранилища, а не публикации в ChatGPT Sites.
